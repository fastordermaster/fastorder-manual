# 패스트오더 사장님 이용 가이드

공개 매뉴얼은 index.html에서 표시됩니다. 배포는 dev 브랜치의 루트를 사용합니다.

안내 콘텐츠는 content.json으로 관리합니다. 콘텐츠 편집기는 admin.html이며 계정·인증키·서버 저장 기능이 없는 로컬 편집 도구입니다. 수정 파일을 내려받아 게시 담당자에게 전달하는 방식입니다. 숨김 항목은 공개용 수정 파일에서 제외되며, 전체 작업 내용은 백업 파일로 보관할 수 있습니다. 백업 파일은 공개 저장소에 올리지 마세요.

첨부 화면은 사용 예시이며 버전·매장 환경에 따라 다를 수 있습니다. 공개 전 새로 추가한 이미지·GIF의 모든 장면과 개인정보를 확인해 주세요.
